# stash
A simple Python tool for scanning image folders and consolidating small collections into organised batches.

## C# Windows application

The Windows Forms port is in [`csharp/`](csharp/README.md). Open `csharp/Stash.sln` in Visual Studio 2022 with the .NET desktop development workload and .NET Framework 4.8 targeting pack installed, select **Debug**, and build the solution.

Run `csharp/Stash.WinForms/bin/Debug/net48/Stash.exe`. Run `csharp/Stash.SafetyChecks/bin/Debug/net48/Stash.SafetyChecks.exe` for the isolated file safety checks. The Python project remains at the repository root.
